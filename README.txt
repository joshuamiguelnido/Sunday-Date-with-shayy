LOVELOVE INVITATION WEBSITE

Open index.html in Chrome, Safari, or another modern browser. The four personal photos are included in assets/ and work offline.

The website includes interactive invitation buttons, scrolling navigation, a love letter, itinerary, and a photo scrapbook.

IMPORTANT: Destination and Fennec Fox images are linked to external public image sources and need an internet connection. Some source sites may restrict direct image loading; the site displays a graceful placeholder if a destination image fails. The photos of the couple are stored locally.

To publish: upload index.html and the assets folder together to a static host such as Netlify Drop or GitHub Pages. Keep the folder structure unchanged. There is no server-side RSVP storage: the Yes buttons display an on-page celebration only.

No specific Sunday date was supplied, so the site intentionally does not invent one. CCF service location, cinema showtime, and dining details should be verified before the date.
